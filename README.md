# House Price Prediction

A machine learning application built with Streamlit to predict house prices based on various features from the Ames Housing dataset.

## 🚀 Live Demo
You can access the live application here: 
**[https://housepriceprediction-ndtzjz6kmpe2yv5dmndki9.streamlit.app/](https://housepriceprediction-ndtzjz6kmpe2yv5dmndki9.streamlit.app/)**

## Features
- **Data Preview**: View the raw dataset used for training.
- **Model Selection**: Choose between different regression models (Linear Regression, Random Forest, Decision Tree, KNN).
- **Interactive Visualizations**: Generate various charts (Line, Bar, Histogram, Heatmap, etc.) to explore the data.
- **Real-time Prediction**: Input custom house features to get an instant price prediction.

## Technologies Used
- **Streamlit**: For the web interface.
- **Scikit-Learn**: For machine learning models and preprocessing.
- **Pandas & NumPy**: For data manipulation.
- **Plotly Express & Seaborn**: For data visualization.
